What GitBot does

Everything you need for GitHub automation

From webhook to Slack notification in milliseconds, with AI in the middle

🔐

Secure OAuth

Sign in with your GitHub account. CSRF-protected OAuth flow with scoped permissions. Your tokens are never exposed to the client.

⚡

Realtime Webhooks

Receives GitHub events (issues, PRs, pushes) via per-repo HMAC-verified webhooks. Idempotent processing handles duplicate deliveries.

🤖

AI Triage

Gemini AI analyzes issue and PR content to suggest labels, assess priority (critical/high/medium/low), and generate summaries.

📋

Configurable Rules

Build rules in the UI: match on event type, keywords, author, labels. Trigger actions: add label, post comment, or notify Slack.

📣

Slack Notifications

Rich Block Kit messages with AI summaries, priority color bars, and direct links to GitHub. Know what matters, instantly.

📊

Live Dashboard

See every event received, every action taken, and every failure. Full audit trail with retry history and processing errors.

The flow

Four steps from event to action

01

Connect a repository

Sign in with GitHub, pick a repo you own. GitBot registers a webhook with a unique secret — GitHub will send events to your bot.

02

GitHub sends an event

When someone opens an issue or PR, the HMAC-signed webhook fires. GitBot verifies the signature and stores the event for processing.

03

Rules engine + AI evaluate

Your configured rules are evaluated. Matching rules trigger actions. If AI triage is enabled, Gemini analyzes and prioritizes the item.

04

Bot acts + notifies

Labels applied, comments posted, Slack pinged — all with full audit logs. Every action is recorded with success/failure status.
